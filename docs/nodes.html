Node reference

All 39 nodes — what each one does, its pins, and every parameter with its default and range. This is the same reference that ships in the application under Help, generated from the source of version 0.3.1, so it cannot drift from the build.

Road / Path

Filters Road
InTerrain
OutHeightRoad maskShoulder mask

Draw a route over the 2D preview and get a grade-limited carriageway. It cuts into hills and fills across dips so the finished surface never exceeds the maximum grade you set.

Width and shoulder are authored in metres, grade in percent. Alongside the terrain it outputs a road mask and a shoulder mask for your material stack.

It shapes terrain only — it does not generate road meshes, bridges or tunnels.

The elevation profile is solved once over the whole route, so a tiled export resolves the same surface on both sides of a seam.

Composite

Layer Stack

Composite Layer
InBaseLayer 1 – 12Mask 1 – 12
OutHeight

Photoshop-style layering for terrain. A base plus three layers, each with a blend mode, opacity, an optional mask and an enable toggle.

19 blend modes. Multiply and Darken cut terrain away, Screen and Lighten build it up, Overlay and Soft Light add contrast without flattening.

Wire a mask into a layer and it only applies where the mask is bright.

Five controls per layer — blend mode, amount, "only where layer has height" and "invert mask" — for up to 12 layers (a new stack starts with 2).
Blend modes: normal, multiply, screen, overlay, soft-light, hard-light, add, subtract, difference, darken, lighten, linear-burn, color-dodge, color-burn, vivid-light, linear-light, pin-light, exclusion, average, max, min.
21 entries in the menu; max and min are terrain-friendly names for lighten and darken, so there are 19 distinct operations.

Output

Height Output

Output terminal HeightOutput
InHeight

The terrain itself. Whatever reaches this node is what exports.

Every graph needs exactly one. If the preview is blank, this is usually what to check first.

Splat Output

Output terminal SplatOutput
InLayer RLayer GLayer BLayer A

Four texture layers your engine blends across the terrain - typically grass, rock, sand and snow.

Feed each input a mask: a 0-1 image saying where that material belongs. Analysis nodes and the mask outputs on River and Flatten Pin are what you wire here.

Exports as an RGBA PNG next to the heightmap.

Water Output

Output terminal WaterOutput
InWater

Terminal, like Height Output and Splat Output: it marks which mask in the graph is standing water, so the 3D viewport can put a surface on it and an export can hand your engine a water map.

Sea level lives here rather than in the view settings, because it is part of the terrain rather than a display preference.

Wire a water mask here — the River node's mask output is the usual source.
