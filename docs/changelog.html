Changelog

What changed in each release, newest first. Written from the point of view of someone using Strata rather than someone reading its source. Current version 0.3.1.

Releases: 0.3.1 · 0.3.0 · 0.2.0

Notable changes to Strata. Dates are release dates on Steam (app 4791200).

The format follows Keep a Changelog. Versions correspond to version in Cargo.toml.

0.3.117 November 2026

Fixed

  • The Unity export preset wrote a file Unity cannot import. It produced 16-bit PNG, and Unity accepts neither: the Terrain Inspector's Import Raw reads RAW only, and the Terrain Tools package's Import Heightmap states the same. The preset now writes 16-bit little-endian raw at the same 2^n+1 resolutions, which is what Terrain > Import Raw expects with Depth set to 16 bit and Byte Order set to Windows. Choose Generic PNG if you were relying on the old output.

0.3.017 November 2026

Added

  • Road / Path node. Draw a route over the 2D preview and get a grade-limited carriageway: it cuts into hills and fills across dips so the surface never exceeds the maximum grade you set. Width and shoulder are authored in metres, grade in percent. Outputs road and shoulder masks alongside the heightmap for your material stack.
  • Place a Flatten Pin while walking. Press P in walk mode to drop a level building pad where you are standing. The node is spliced into the graph before the height output, so you can keep walking and keep siting. A brief on-screen confirmation names the pin.
  • Crash reports. If Strata hits an unrecoverable error it now writes a report instead of vanishing: version, reason, source location, OS and architecture, GPU name and a backtrace. Written to %LOCALAPPDATA%\Strata on Windows and ~/.local/state/Strata on Linux, and the path is printed on exit.

Changed

  • Progressive evaluation. Changing a parameter now redraws immediately at draft quality and refines to your chosen detail 180 ms after you stop adjusting. Dragging a slider costs roughly a third of what it did.
  • Smaller, faster binaries. Link-time optimisation is enabled and the build is a single codegen unit. The Windows executable is 46% smaller (39.2 MB to 21.3 MB) and the Linux executable 24% smaller (34.8 MB to 26.4 MB).
  • The editor warns when a road is authored narrower than the preview's sample spacing, rather than quietly drawing it wider than you asked for.

Fixed

  • Roads no longer disagree across tile boundaries in a tiled export. The elevation profile is now derived once over the whole route against the full extent, then stamped per tile, so neighbouring tiles resolve the same surface. Seam error measured at 0.000000, down from ~16 m. The equivalent problem in the River node is known and not yet fixed.
  • The version reported in crash reports and on the build is now the real release version. Earlier builds reported 0.1.0 regardless.

0.2.0Rust rewrite

Strata has been rebuilt from the ground up in Rust, replacing the Electron build that shipped from May to November 2026. Existing .strata projects open in the new version — node ids, pin types, field keys and defaults were reproduced deliberately so saved work is not stranded.

Added

  • Native Linux build, alongside Windows. Runs natively on Steam Deck and Linux desktops with no compatibility layer.
  • Selectable preview detail — Draft (512), Balanced (1024) and Fine (2048) sampling, independent of physical dimensions and export settings. The Detail menu reports physical sample spacing in metres and an estimated heightmap memory cost before you commit to a level.
  • Walk and follow cameras for inspecting terrain at player scale, in addition to the orbit camera. F2 opens Display and F3 opens Camera while in walk or follow mode.
  • Guided tour covering node wiring and navigation, reopenable at any time from the Help menu.
  • Textured 3D viewport with grass, rock, dirt, snow and riverbed materials driven by the splat stack, plus water rendering.

Changed

  • Rewritten on Rust and wgpu. Terrain evaluation runs as GPU compute kernels rather than in a browser runtime, and the application ships as a single self-contained executable instead of a bundled browser.
  • Height, splat, water and walking collision now all evaluate at the selected preview resolution, so what you walk on matches what you see.
  • The 3D viewport keeps the previous terrain texture on screen until its replacement is ready, instead of flickering during a rebuild.
  • Physical map dimensions persist with the project.
  • Save and Save As report failures in the editor and retain the previous file path when a save fails, rather than silently dropping it.

Fixed

  • Mountain Ridge raised terrain along the top edge of the map regardless of where the ridge spline was placed. The GPU shader read one spline point past the end of the uploaded data, and the out-of-bounds read introduced a phantom control point near the origin. The shader now derives its point count from the uploaded texture. Verified with a dedicated regression check (cargo run --bin ridgecheck) across several seeds, which also covers shared tile boundaries.

Known limitations

  • Evaluation is synchronous, so a complex rebuild at Fine detail can briefly pause the interface. Background evaluation with cancellation is planned.
  • Selectable resolution does not add detail at continental scale: a 64 km world at 2048 samples still has roughly 31 m between samples.
  • Export writes heightmaps and masks but not yet an explicit scale manifest; engine import still leans on preset defaults.
